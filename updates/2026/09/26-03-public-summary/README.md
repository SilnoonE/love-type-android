# 공개 학습 문서 범위 정정

개인 공부용 상세 해설 대신 **8쪽 공개용 개발 요약**만 게시합니다. 동일 내용의 Markdown도 요약본으로 교체했습니다.

- 공개 PDF는 앞으로 10쪽 이내로 제한합니다.
- 이전 두 개발 기록과 태그 이름, Android 소스 85개 파일은 보존했습니다.
- 개인 자료 노출을 줄이기 위해 기존 두 커밋과 태그에서도 해당 문서와 연결 설명·무결성 목록만 정정했습니다. 이 예외 작업으로 커밋 식별자는 바뀌었습니다.
- 긴 개인 학습서와 정정 전 저장소 백업은 로컬에만 보관합니다.
- 이미 내려받은 복사본이나 GitHub의 과거 SHA 캐시까지 회수했다는 의미는 아닙니다.
