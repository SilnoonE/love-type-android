# 저장소 포함·제외 정책

## 포함

Kotlin/XML 소스, 앱 이미지, 테스트 소스, Gradle wrapper와 설정, 개발 과정, 코드 해설, 명시적으로 선택한 PDF.

## 제외

운영 광고 ID, 서명 키(확장자가 없는 키 파일 포함), 비밀번호·토큰, local.properties, IDE 설정, 로컬 JDK 설정, 사용자 DB와 백업, APK/AAB, release/build/.gradle 캐시.

원본 프로젝트를 복사할 때 허용한 경로와 확장자만 선택합니다. `.gitignore`에만 의존하지 않습니다. 원본 앱의 코드나 광고 설정은 수정하지 않습니다.

공유 사본의 광고 식별자는 다음 Google 공식 테스트 식별자로 치환합니다. 광고 동작 자체를 새로 설계하지 않아 학습용 소스 구조를 유지합니다.

- 샘플 앱: `ca-app-pub-3940256099942544~3347511713`
- 고정 배너: `ca-app-pub-3940256099942544/6300978111`
- 전면 광고: `ca-app-pub-3940256099942544/1033173712`

출처: [Google 테스트 광고 문서](https://developers.google.com/admob/android/test-ads), [SDK 초기 설정 문서](https://developers.google.com/admob/android/quick-start).

사용자의 명시적인 선택에 따라 운영 광고 ID·서명 키·개인정보를 제외한 전체 소스·문서를 공개합니다. 비공개로 처음 준비한 뒤 과거 커밋의 업로드 파일까지 검사하고 공개로 전환했습니다. 별도의 오픈소스 라이선스는 임의로 부여하지 않았습니다. 공개 열람과 재사용 라이선스 부여는 구분합니다.

PDF는 사용자가 요청해 작성한 학습 문서입니다. 원본 앱 폴더 이름 등 설명용 경로가 포함될 수 있으며, 사용자 DB나 인증정보는 포함하지 않습니다.
