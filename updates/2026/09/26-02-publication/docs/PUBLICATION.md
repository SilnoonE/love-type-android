# 공개 범위

사용자가 선택한 범위: **운영 광고 ID·서명 키·개인정보만 제외하고 전체 소스도 공개**.

## 포함

앱 소스 85개 파일, UI 리소스, 테스트 소스, Gradle 설정, 개발 과정, 구조 설명, GitHub 코드 해설과 8쪽 공개용 PDF.

## 제외·가공

- 실제 운영 광고 ID는 원래 업로드부터 Google 공식 테스트 ID로 치환했습니다.
- 확장자가 없는 서명 파일을 포함한 키·인증정보는 허용 목록 복사에서 제외했습니다.
- local.properties, IDE·JDK 로컬 설정, 개인 DB, 백업, APK/AAB와 캐시는 포함하지 않았습니다.
- 개인 이메일과 사용자 홈 디렉터리 경로가 공개 파일에 들어가지 않았는지 텍스트와 PDF에서 확인했습니다.

기존 비공개 기록을 그대로 공개해도 되는지 과거 Git 이력의 파일까지 확인했습니다. 처음 스냅샷에 실운영 키나 서명 파일이 포함된 상태에서 나중에 삭제한 구조가 아닙니다.

이전 날짜 폴더는 그대로 남고, 이번 전환 기록은 별도 폴더와 커밋·태그로 추가합니다.
