## 이번 기능

| 영역 | 구현 |
|---|---|
| 홈 | 오늘 질문, 기존 테스트, 최근 카드 3개 |
| 질문 | A/B/C/D 선택, 선택 표시, 제출 |
| 콘텐츠 | 질문 30개, 선택지별 결과 120개 |
| 출제 | 첫 사용일 기준 날짜 계산, 30일 순환, 저장된 스냅샷 우선 |
| 결과 | 제목·해석·대화 문구, 원문·고른 답, 오늘 답변 수정 |
| 기록 | 날짜별 upsert, 질문 전체 스냅샷, 즐겨찾기 |
| 모음집 | 최신순 목록, 전체·즐겨찾기 필터 |
| 공유 | 별도 XML을 PNG로 그려 FileProvider로 전달 |
